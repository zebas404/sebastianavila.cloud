Privacy Policy

Last updated: October 5, 2026

Who this applies to

This policy covers n8n zxbCloud, a private automation run by Sebastian Avila on his own home server. It is for personal use only and is not offered to the public. The only Google account it accesses is Sebastian's own.

What data it accesses

With Sebastian's authorization, the automation reads new messages in his Gmail mailbox and reads and creates events in his Google Calendar. It uses this access for one purpose: when an email confirms an appointment, meeting or event, it creates the matching calendar event.

How data is processed

The content of each new email is sent to the Anthropic API (Claude) only to decide whether it describes an event and to extract its date, time and place. Nothing else is done with it.

Storage and sharing

Emails are not copied, stored or sold. Data is never shared with third parties beyond the processing described above, and it is not used for advertising or to train models. Execution logs stay on the private home server.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account → Third-party connections.
